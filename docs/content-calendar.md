# Content calendar

The calendar is the app's home page and the central dashboard for every planned video.

## Choosing dates

- **Presets:** 1, 7, 15, 30, 60 or 90 days from a chosen start date. "Today" jumps to today in IST.
- **Custom:** any From and To dates, up to one year.
- **Layouts:** "Table" shows every column. "Calendar" shows a Monday–Sunday grid.

Your last choice is remembered in this browser.

## Columns

Date · Day · Weekly theme · Video idea · Video type · Script status · Video status · Final version · Publishing status.

The weekly theme follows the Monday–Sunday strategy:

| Day | Theme |
|---|---|
| Monday | Relatable English Problems |
| Tuesday | Learn With Sia |
| Wednesday | Emotional / Story |
| Thursday | Trend / Meme / Viral |
| Friday | Challenge / Interactive |
| Saturday | Entertainment + English |
| Sunday | Transformation / Motivation |

The October lessons were written before these themes, so several don't match their day's theme yet.

## Statuses

Each status is worked out from real saved records, never typed in by hand.

| Status | Meaning |
|---|---|
| Idea Generated | The item exists but has no saved script yet. |
| Script Ready | At least one script version is saved. The newest version number is shown, plus "approved" when it's approved. |
| Video Generating | A video attempt is queued or in progress. |
| Video Ready | A video is ready to finish, or a finished video is waiting for review. |
| Needs Changes | The latest attempt failed or is held, a finished video failed checks, or a reviewer ticked "Changes requested" in Final Review. A newer take clears it. |
| Approved | A final video is approved. The final version column shows which video and script. |
| Downloaded | The approved video has been downloaded. |
| Published | Someone marked it published, with platforms and date. This needs an approved video. |

Click a status count to filter to it. Days with nothing planned show "Plan a video", which creates a dated idea and opens its Script Workspace. "Export CSV" downloads the rows in the current range.
