# Phase 1: idea to approved download

Open Video studio or create an idea in Idea backlog. Each idea opens its Script Workspace.

1. Edit the brief, hook, full spoken script, scene plan, dialogue, voiceover notes, captions, CTA and generation prompt. The field labelled **Full spoken script · sent to Cartesia** is the actual spoken transcript; synchronize scene notes after revisions.
2. Save Draft for work in progress. Save as New Version creates an immutable script snapshot with an optional name and change note. Edits to approved scripts always create a new version.
3. Run Script Review. Inspect the six categories, improvements and readiness blockers. Optional AI draft/review uses provider credits. Scores do not predict performance.
4. Compare any two scripts or restore an earlier script as a new current version. Select the script version to generate.
5. In Generate, select a saved single-person Sia frame or upload a prepared scene. Review it, confirm rights and save a new version. Connections must pass; owner duration/daily limits apply.
6. Generate New Video Version creates a separate paid attempt. Resume checks the saved attempt. An interrupted paid step is held for reconciliation to avoid duplicate charges. Actual voice duration is checked before buying video clips. Lessons are split into ≤14-second clips for the provider.
7. Open Captions & Final Video. Edit timed caption cues; save the caption draft. Render in Chrome with this tab visible, or upload a finished vertical edit of the same take. Each finished file is a separate immutable export.
8. Compare video exports. Watch the full video, record review comments, and complete all QA checks. Approve Final Version binds approval to that exact file.
9. Approved downloads contains only **Approved and Ready to Download** files. Download and publish manually using the checklist.

Keys stay encrypted on the server. Never paste credentials in script fields. Provider setup, limits and generation are owner-controlled; sharing this private workspace and granting a team role are separate administrative actions.

Current finishing includes captions, vertical framing and an optional logo. Use a prepared background frame or an external edit for complex location/map transitions. Keep all source and final versions in history.
